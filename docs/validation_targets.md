## 三、差靶点归因分析（2026-08-19 实证）

### 1BJ1（VEGF–Fab-12）——多因素叠加

**剔除实验截断点（censored: g92a/i83a/m81a）后，R = −0.721、Spearman = −0.745**：

1. **实验值截断主导**：0.0×6、3.69×4（检测限饱和），弱效应面板中"正确测量"的点本来就少——可排序的信息量低
2. **剔除截断点后呈负相关**：剩余 11 个弱效应点的预测与实验**反相关**——该靶点的弱效应预测不仅是噪声，而是方向性错误
3. **与 1CZ8 的对照**（同一 VEGF 抗原、同一突变面板、亲和力成熟抗体 Y0317，R=0.64）：1BJ1 的母体 Fab-12 亲和力更弱、界面更动态——**弱结合界面+弱效应突变是物理上最难的组合**
4. 已知并发因素：H90A/Q89A 质子化耦合位点、g92a/g88a 未收敛过冲（+16~17）

**修复路径**：① censored 合法剔除已实现并应默认启用（这些点不该参与排序指标）；② g92a/g88a 端点系综重跑；③ H90A 质子化变体；④ **该靶点弱效应面板应标记为"指标参考性低"而非管线失败**

### 2JEL（fit 面板）——实验数据量子化，已移出验收集（2026-08-22 定性，2026-08-31 用户决策移出）

- 面板 21 个突变中 **13 个实验 ddG 精确为 0.0（62%）**；源数据（AB-Bind，JMB 1998，DOI 10.1006/jmbi.1998.1888）43 条中 22 条为 0.0
- 数值严重量子化：{0, ±0.41(≈RT·ln2), 2.75(≈RT·ln100), 4.13(≈RT·ln1000)}——原实验只报"无影响/2×/100×/1000×"档位，"无影响"记为 0
- **有效排序层级仅 ~6 档**，R≈0 是实验分辨率天花板而非方法失败；MAE 1.02 其实不差

**处置**：**移出验收集**（用户决策 2026-08-31），不计入任何汇总/分靶点指标；job 数据保留供参考。

### 3BE1——已归因（2026-09-08）：纯 P1 芳香删除病

- **干净的分裂**：普通突变 n=9 R=**0.93**（极好）vs P1 芳香删除 n=7 R=**−0.26**（反相关！）
- 弱效应面板（span 3.2）+ 芳香删除子集动态范围膨胀 4.2× → P1 点把排序压垮
- 处置：P1 水合播种推广的直接受益者（w50a 已 9.73→5.93）；P1 类修复后 3BE1 预期回到 R≈0.7+ 区间（普通+P1 混合）

### 1DVF——芳香删除锚定的假象

**剔除全部 Y/W→A 突变后，R = −0.050、Spearman = −0.383**：

1. 表观 R=0.621 **完全由 Y/W 大删除点承载**（它们方向对、数值错）
2. 剩余 9 个"常规"突变（H30A/S93A/N56A/T30A/H33A/I101A/N55A/Q104A/Y32A）也呈负相关——**极性小突变同样存在系统性高估**（N56A 4.53 vs 1.17、Q104A 6.75 vs 1.64、I101A 3.53 vs 2.71）
3. 说明系统性高估不限于芳香删除——**极性突变普遍被高估 |ddG|**（力场端点效应）

**修复路径**：① Y/W 点的 RID/REST2 端点系综已验证（err −46~−72%），推广到全部 1DVF Y/W job；② 极性小突变的系统性高估 → 双力场（E6）对照验证；③ 1DVF 双抗独特型界面（Fv–Fv）本身动态性强，考虑更长端点平衡。

## 四、统一报告口径（已固化到 `_benchmark_metrics_from_pairs`）

每次评估同时输出：
1. **pooled**：R / Spearman / MAE / 三分类 BA（含 censored 标注）
2. **per-target**：逐靶点 R / Spearman / MAE / 偏移 + **靶点中位数**（主口径）
3. **剔除口径**（诊断用，不作主口径）：QC 收敛过滤、误差去极值——用于暴露杠杆结构，不用于美化

## 五、全局结论（2026-08-19 修正版）

1. 管线在 **6/8 靶点上可用**（中位 R=0.64），且失败高度特异
2. **跨靶点一致的系统性问题只有一个**：极性/大删除突变的 |ddG| 系统性高估 → 端点系综（已验证）+ 双力场（待验证）双路线
3. 差靶点（1BJ1/3K2M）的主因是**数据质量**（截断值、n 太小）而非管线能力——应合法标注，不计入能力判负
4. 弱效应精细排序（Spearman<0.4 处）是当前真实短板，依赖单点物理改善，无指标口径捷径
