# AB-Bind Source Files

- `AB-Bind_experimental_data.csv`: original upstream experimental table from the
  public AB-Bind GitHub release.
- `ab_bind_complex_annotations.csv`: project-local complex metadata used to map
  AB-Bind mutation chains onto `antibody` / `antigen` sides and to separate
  strict `antibody-antigen` cases from other AB-Bind complex classes.

The annotation table is intentionally local to `abag-rbfep`. It reflects the
project's stricter RBFE benchmark boundary rather than the broader raw AB-Bind
 release contents.
